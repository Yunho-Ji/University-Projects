# 🎓 University-Archives: 개발의 시작과 성장 기록

이 레포지토리는 대학 시절 및 초창기 학습 과정에서 진행했던 소중한 프로젝트들을 모아놓은 아카이브입니다.
단순한 코드를 넘어, 개발자로서 기초를 다지고 문제 해결의 재미를 처음으로 느꼈던 기록들입니다.

---

## 📂 프로젝트 목록

### 1. [인디언 포커 (C++)](./인디언포커)
- **설명:** C++ 기초 문법을 활용해 처음으로 구현한 베팅 게임.
- **학습 포인트:** 조건문, 반복문, `rand()`를 활용한 확률 로직 설계.
- **회고:** 현재의 `다이스 던전 크롤링(DDC)`의 모태가 된 확률 로직의 기초입니다.

### 2. [JSP 웹 기초 과제](./1402106097_jiyunho)
- **설명:** JSP, JavaScript, HTML을 활용한 기초 웹 인터페이스 실습.
- **학습 포인트:** 클라이언트-서버 구조의 이해 및 DOM 조작 기초.
